# 🏪 Product Inventory Management System

## 🚀 Getting Started

### Prerequisites
Before you begin, ensure you have the following installed:
- Node.js (v14.0.0 or higher)
- MongoDB
- Git
- Your favorite code editor (VS Code recommended)

### 🔧 Installation Steps

1. **Clone the repository**
   ```bash
   git clone [your-repository-url]
   cd product-inventory-management
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
    - Create a `.env` or change file in the root directory
    - Add the following variables:
      ```
      PORT=3000
      MONGODB_URI=mongodb://localhost:27017/product-inventory
      NODE_ENV=development
      ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

Good luck with your implementation! If you have any questions, don't hesitate to ask.
